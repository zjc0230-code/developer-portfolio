# 原始资料

> 存放各类原始参考资料、未整理素材、本地备份文件等。
> 此目录内容**不会**被 `npm run sync:site` 同步到对外展示页。
> 
> 与 `内部资料/` 的区别：`内部资料/` 存放的是不便公开的个人信息、简历方向等；
> `原始资料/` 存放的是待整理的技术参考资料、外部收集的素材等。

## 目录约定

请按资料类型建立子目录，如：
- `行业报告/` — 第三方行业分析报告
- `技术文档/` — 外部技术文档、白皮书
- `图片素材/` — 待使用的架构图、截图等

## 使用规则

- 文件命名使用中文或英文均可，建议加日期前缀便于追溯
- 整理完成后应移动到对应的 `docs/` 子目录（如 `行业解决方案/` 或 `博客/`）
- 请勿在此目录存放敏感个人信息（那些应放 `内部资料/`）
