# Kaoker 直播课程收费体系

| 字段 | 内容 |
|------|------|
| **角色** | 项目负责人 |
| **周期** | 2017 – 2019 |

## 一句话

互联网烘焙社区 **150 万+** 用户的内容付费：课程购买、会员包月、打赏；虚拟订单与中台化收费能力。

---

## 情境（Situation）

Kaoker 为美的旗下互联网烘焙社区，需从免费内容走向可持续付费（课程、会员、打赏）。

## 行动（Action）

- 设计收费体系与中台：购买、包月、打赏统一订单模型。
- 独立开发虚拟订单、VIP 会员；协同支付网关与账单。
- 带领小组完成平台后端交付。

## 结果（Result）

150 万+ 用户稳定运营；拓展美的电商**内容付费**场景。
