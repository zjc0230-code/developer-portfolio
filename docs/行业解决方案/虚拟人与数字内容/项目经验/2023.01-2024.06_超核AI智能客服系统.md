# 超核 AI 智能客服系统

| 字段 | 内容 |

## 一句话

腾讯**全系游戏**智能客服平台，大模型 + RAG；日均 **500 万+** 咨询，准确率 **94%**，客服成本约 **-60%**。

---

## 情境（Situation）

人工客服成本高、响应慢、标准答案难以覆盖海量游戏知识。

## 任务（Task）

设计可**多游戏标准化接入**的 AI 客服架构，对降本与准确率负责。

## 行动（Action）

- 大模型 + RAG 问答；多轮对话与意图识别。
- 全链路监控；制定接入规范与评测集。
- 对齐业务预期：AI 边界 + 人工兜底（约 5%）。

## 结果（Result）

| 指标 | 结果 |
|------|------|
| 规模 | 日均 500 万+ 咨询 |
| 质量 | 回复准确率约 94% |
| 成本 | 客服成本约 -60% |
| 满意 | 用户满意度 +35% |
