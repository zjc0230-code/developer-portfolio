## 一句话

私域场景 **20+ 游戏 IP** AI 角色互动小程序；配置化人设与 RAG，与混元 7B 协作评测，离线拟人/安全指标达业务预期。

---

## 情境（Situation）

- 知几作为游戏社区/工具入口，需在私域（小程序）提供**拟人化 IP 对话**，支撑拉新与留存。
- 多 IP 人设、多游戏知识库并存，不能每 IP 重写一套服务。
- 2023.09 起与混元团队合作，在 **7B** 规模模型上验证安全、拟人与成本平衡。

## 任务（Task）

- 设计小程序后端 + AI 对话链路（并发、流式、审核）。
- 建立多 IP **配置规范**与运营自助接入流程。
- 输出可复用的评测集与上线门禁（与后续 Lily、虚拟人直播共用思路）。

## 行动（Action）

### 架构

- **Golang 微服务：** 对话网关 + 角色配置中心 + 按 IP 隔离的 RAG 知识库。
- **配置化：** 人设 Prompt、知识库、兜底策略版本化，运营可灰度。
- **安全：** 输入/输出审核；敏感场景固定兜底回复。

### 模型与评测

- 混元及内部模型 A/B；离线评测集覆盖拟人度、安全、事实性。
- 业务口径：离线关键指标**优于同期 ChatGPT 对照**（内部评测报告，不对外披露明细）。

### 与平台能力复用

- 对话网关、内容安全与 [Virtual Idol](../技术方案/Virtual-Idol架构导读.md) 同族能力；海外 [PUBG Lily](../../游戏与互动娱乐/项目经验/2024.07-2024.11_PUBG智能管家Lily.md) 监控与降级经验反哺知几侧容量评估。

## 结果（Result）

| 维度 | 结果 |
|------|------|
| 覆盖 | **20+** 游戏 IP 角色上线 |
| 模型 | 7B 混元合作路径验证，安全+拟人达标 |
| 工程 | 配置化接入，缩短新 IP 上线周期 |
| 业务 | 支撑私域留存与运营活动转化 |

## 技术栈

Golang · 微服务 · 大模型 · RAG · 小程序后端 · 内容安全 · Prompt 版本管理
