## 1. 系统定位

为游戏与直播提供**可配置、可扩展**的虚拟角色服务：NPC 对话、TTS/ASR、口型与肢体驱动，Go + tRPC 统一底座。

## 2. 四层架构（速览）

| 层 | 职责 |
|----|------|
| cmd | 启动、路由、HTTP/tRPC/SSE |
| logic | idol / npc / aigc / emotion / mouth / aiimg |
| repo | dao、redis、tts、llm、敏感词、长连接 |
| model | 领域模型与配置 |

## 3. 通信模式

- **HTTP / tRPC：** 同步 RPC  
- **SSE / WebSocket：** 流式对话，降低首字延迟  

## 4. 性能关键设计

| 优化 | 效果 |
|------|------|
| 流式输出 | 首字 2.5s → 0.3s（约 -88%） |
| TTS/动作缓存 | 命中率 40% / 35–45% |
| 并发与连接池 | 吞吐 +20% |
| Session 跨实例 | 水平扩展 |

## 5. 安全四重

签名验证 · 防重放 · 限流 · ACE 敏感词（输入输出双向）

## 6. 配置热更

七彩石：游戏级 / 机器人 / 限频 — **无需重启**
