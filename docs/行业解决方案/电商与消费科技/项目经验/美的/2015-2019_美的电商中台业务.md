# 美的电商中台（订单 / 支付 / 商品）

| 字段 | 内容 |
|------|------|
| **角色** | 高级后台研发工程师 / 架构参与 |
| **周期** | 2015 – 2019 |
| **产业** | [电商与消费科技](../../行业解决方案.md) |

## 一句话

家电垂类领先电商平台，**年流水 200 亿+**；主导交易中台与支付网关，单机 TPS **1000+**，双 11 **10 万+ 单/日**。

---

## 情境（Situation）

多品牌（美的、小天鹅、东芝）、多模式（自营/供销/代销/代收代付）共用中台，需高可用与可扩展。

## 行动（Action）

- 订单中心：购物车、多次支付退款、全流程售后。
- **聚合支付网关：** 微信/支付宝/银联/银行直连统一接口。
- Thrift 升级、RabbitMQ 事件总线解耦 10+ 微服务。
- 组件复用率 +60%。

## 结果（Result）

| 指标 | 结果 |
|------|------|
| 流水 | 200 亿+ 稳定 |
| 性能 | 下单 TPS 1000+ |
| 稳定 | 调用成功率 99.9%，架构 99.9% |
| 效率 | 研发效率 +30% |
