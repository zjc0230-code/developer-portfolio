# 美的智能扫地机器人 · 通讯框架与算法

**角色：** 核心开发 · **周期：** 2016.05 – 2019.05

## 项目背景

嵌入式通讯与机器人算法预研，支撑扫地机产品与云端协同。

## 核心工作

- C++：ARM 与云端 TCP + select 多路复用，Linux/Windows 双平台。
- SLAM、路径规划、全覆盖导航、动态避障；自创二值轮廓地图全局重定位（断点续扫）。
- ROS / Cartographer / OpenCV 验证；Faster-RCNN、Mask R-CNN 等设备侧可行性研究。

## 核心成果

- 完整通讯框架落地；重定位算法解决续扫难题；沉淀嵌入式与视觉 AI 经验。

## 技术栈

C++、TCP、SLAM、ROS、OpenCV、深度学习、IoT
