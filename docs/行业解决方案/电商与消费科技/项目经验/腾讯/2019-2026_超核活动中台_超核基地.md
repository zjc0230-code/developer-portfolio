# 超核活动中台 · 超核基地

| 字段 | 内容 |
|------|------|
| **角色** | 技术负责人 |
| **周期** | 2019 – 2024 |
| **公司** | 腾讯 · 超核 |
| **产业** | [电商与消费科技](../../行业解决方案.md) |

## 一句话

腾讯游戏**高付费用户运营活动中台**，支撑 10+ 产品、数百万用户；新活动开发 **20 天→7 天**，2022 年总打开 **2 亿次**，获 IEG 成本优化突破奖。

---

## 情境（Situation）

- 超核玩家需要专属运营载体：日常活动、赛季活动、高端权益（酒店、公益、NFT 等）。
- 早期单体架构导致重复开发、发布步骤多（曾达 18 步）、扩展困难。
- 需同时支撑**高并发打开**与快速赛季迭代。

## 任务（Task）

- 推动活动业务**中台化**与微服务化，划分核心领域。
- 建设超核专属标准化研发框架，提升交付效率与可观测性。
- 保障季节性大促与全年赛季稳定运行。

## 行动（Action）

- **领域拆分（10+）：** 活动、用户、游戏、组队、排行榜、酒店预订、公益捐款、至信链 NFT 等。
- **技术栈：** TRPC、七彩石、北极星、智研、蓝盾；大仓、PB 模板、脚手架、协议自动化 CI/CD。
- **流程优化：** 开发流程 **18 步→7 步**；代码自动化部署率 100%。
- **可观测：** 日志、指标、事件告警、链路追踪体系。
- **运营支撑：** 超核基地、嘉年华、鹅伴公益（认捐 150 万+）、核嘉欢、迪士尼酒店等。

## 结果（Result）

| 指标 | 结果 |
|------|------|
| 产品 | 10+ 款产品落地（小程序、基地等） |
| 用户 | 累计数百万；2022 年使用人数 62 万 |
| 活跃 | 2022 年总打开 2 亿次；最高 DAU 55859 |
| 活动 | 2022 年 164 个赛季活动；平均参与率约 68% |
| 效率 | 新活动周期 20 天→7 天；研效 +50%+ |
| 转化 | 2023 非超核转化率 15.3%；平均赛季参与率 57.6% |
| 稳定 | 可用性 99.95%+ |

## 技术栈

TRPC · 七彩石 · 北极星 · 智研 · Protobuf · 微服务 · 中台化 · DDD
