## 模板 1：云上电商架构

面试官，我做电商云上架构，核心逻辑是以业务为核心，搭建高可用、可弹性、低成本的云上全链路架构，全程围绕电商的「流量波动、交易安全、成本可控」三大核心诉求来落地。

**怎么做（四步）：**

1. 梳理六大模块：前端商城、交易支付、订单、库存、用户、数据，明确各模块诉求。  
2. 云上选型：VPC 隔离、SLB、ACK+弹性伸缩、RDS 读写分离、Redis 热点、OSS+CDN、安全合规产品。  
3. 全链路监控与 FinOps：流量/延迟/可用性告警，混合计费、冷热分层。  
4. 容灾：多可用区、备份、应急预案，保障交易不中断。

**三大难点：**

- **大促峰值：** 流量 10×+ → 预估容量、弹性、CDN/SLB 分流、非核心熔断。  
- **安全合规：** WAF、加密、等保审计。  
- **成本：** 性能与成本平衡 → 弹性缩容、架构优化提升利用率。

## 模板 2：AI 在电商/业务场景落地

**四步：** 需求拆解（降本 60%、提效）→ 选型（大模型+RAG/Agent+GPU）→ POC（准确率、时延）→ 复盘优化。

**三大坑：**

1. **预期管理：** 不对齐「100% 准确」→ 用数据讲 95%+人工兜底。  
2. **数据：** 标注不足 → 优先 RAG；训练合规。  
3. **成本效果：** 先 API 轻量验证，再微调；全程跟踪 ROI。
