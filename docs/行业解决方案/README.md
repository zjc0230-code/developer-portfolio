项目一：AI 短剧生成平台（核心标杆项目，占面试 60% 时间）
项目时间：2025.09-2026.03
项目背景：短剧行业内容生产效率低，单集剧本 + 分镜 + 配音需 3-5 天，外包成本高达 8000 元 / 集，公司计划打造 AI 全链路生成平台，实现降本增效。
我的职责：技术负责人，独立完成整体架构设计，带领 3 人后端团队实现从 0 到 1 上线，负责 AI 模块与传统后端系统的融合。
核心工作：
设计 "剧本生成→分镜拆解→多模态合成→审核发布" 全链路流水线架构，采用事件驱动模式解耦各模块，支持任务重试和断点续传
针对大模型剧本质量不稳定问题，实现多 Agent 协作生成架构：策划 Agent 写大纲、编剧 Agent 写剧本、审核 Agent 做合规校验，引入人类反馈闭环
解决长视频生成性能瓶颈：通过任务分片、GPU 资源池调度、预生成常用素材，将单集生成时间从 45 分钟压缩至 8 分钟
对接阿里云 OSS 和 CDN，实现生成内容的自动存储和分发，设计多级缓存架构，降低用户等待时间
项目成果：
业务成果：单集制作成本降至 1200 元，生产效率提升 5 倍，平台上线 3 个月累计生成短剧 1200 + 集，月流水突破 180 万元
技术成果：系统支持 1000 并发任务，GPU 资源利用率从 28% 提升至 72%，剧本一次通过率从 41% 提升至 83%
个人成果：沉淀 AI 生成平台通用架构，申请 2 项技术专利，培养 2 名 AI 后端工程师
项目二：MCP 模型上下文服务技术攻坚（技术攻坚项目，占 25% 时间）
项目时间：2026.01-2026.02
项目背景：原有 AI 系统各应用独立维护上下文，存在数据孤岛、重复计算、上下文不一致问题，且无法实现跨应用的知识共享。
我的职责：独立负责方案调研、设计与实现，打造公司统一的 MCP（模型上下文协议）服务。
核心工作：
深度调研科大讯飞 SkillHub、OpenAI MCP 等主流方案，自研轻量级 MCP Server，支持工具注册、上下文管理和权限控制
实现统一向量知识库，采用 Milvus 集群 + 分层存储架构，支持多租户数据隔离和增量更新
设计上下文压缩和动态加载机制，根据任务复杂度自动调整上下文窗口，解决长上下文 token 消耗过高问题
提供标准 HTTP 和 gRPC 接口，无缝对接公司内部所有 AI 应用
项目成果：
技术成果：统一管理公司 12 个 AI 应用的上下文，重复计算减少 65%，平均 token 消耗降低 42%，跨应用知识共享准确率达 96%
落地成果：该服务已成为公司 AI 技术中台核心组件，新应用接入时间从 2 周缩短至 2 天
个人成果：输出《MCP 服务最佳实践》内部文档，在公司技术分享会做主题演讲
项目三：AI 营销工作流自动化平台（业务落地项目，占 15% 时间）
项目时间：2025.11-2025.12（2 周）
项目背景：市场部每日需重复处理大量文案生成、数据统计、报表发送工作，人力成本高且易出错，要求快速上线一个低成本解决方案。
我的职责：独立负责方案选型、开发与交付，全程与市场部对接需求。
核心工作：
快速评估技术方案，选择Coze 低代码平台 + N8N 工作流引擎的组合，避免从零开发，大幅缩短周期
设计 12 个标准化工作流模板，覆盖短视频文案生成、小红书笔记撰写、用户数据统计、日报自动发送等场景
对接公司内部 CRM 和电商平台，实现数据自动拉取和处理，无需人工导入导出
开发简单的 Web 管理界面，支持市场人员自行修改模板和调整参数
项目成果：
业务成果：2 周内完成上线，市场部日常重复工作减少 80%，每月节省人力成本 3.5 万元
用户反馈：平台日活达 28 人，用户满意度 94%，后续又扩展了客服、运营等部门的 5 个场景
个人成果：验证了低代码 + AI 在企业内部的落地价值，形成了 "快速原型→验证→迭代" 的轻量级交付方法论
