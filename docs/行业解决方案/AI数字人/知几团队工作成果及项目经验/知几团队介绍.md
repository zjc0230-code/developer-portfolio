# 腾讯游戏知几团队介绍

> 知几实验室（ZhijiLab）是腾讯游戏旗下专注于游戏 AI 与数字人技术的核心团队。以"通过 AI 让游戏更好玩，让玩家更快乐"为使命，致力于打造全球领先的游戏 AI 基础设施与数字人平台。

---

## 团队概况

- **全称**：腾讯游戏知几实验室（ZhijiLab）
- **定位**：游戏 AI 与数字人技术核心团队
- **使命**：通过 AI 让游戏更好玩，让玩家更快乐
- **核心能力**：大语言模型（LLM）、多模态交互、语音合成（TTS）、数字人驱动、游戏智能运营、内容安全审核
- **技术栈**：Go + tRPC 微服务架构、大模型 + RAG、流式 SSE、向量检索、VLLM 推理、Prometheus/SkyWalking 全链路可观测
- **服务规模**：覆盖 200+ 款游戏，服务 4000 万+ 玩家，累计消息量超 100 亿次

## 能力地图

| 能力域 | 要点 | 成果摘要 |
|--------|------|----------|
| 服务架构 | Go + tRPC 五层微服务、SSE 流式 | 首字延迟 2.5s→0.3s（-88%），数十亿级日交互量 |
| 多模态管线 | TTS/口型/肢体/3D 面部驱动 | 天刀 智能NPC 多模态升级、Virtual Idol 平台化、谷小雨广电级渲染 |
| LLM 与 RAG | 大模型精调 + 向量检索 + 知识库 | 客服准确率 94%，智能NPC 人设符合率 99%，VLink 准确率 93%+ |
| 纯语音交互 | 语音指令/语音聊天/ASR/NLU | 和平第五人行业首创，天天象棋无障碍扩展 |
| 运营场景 | 直播、小程序、客服、游戏 智能NPC、私域 | 200+ 游戏覆盖，客服成本约 -60%，私域用户超千万 |
| 可观测 | 七彩石、北极星、Prometheus、SkyWalking | 全链路追踪 + 水平扩展 + Session 共享 |
| 海外部署 | 多地区私有化、合规审查 | 10+ 地区上线，合规审查通过率 100% |
| 安全合规 | 签名验证、双向敏感词、多级降级 | 四重安全保障，无重大安全事故 |
| 模型工程化 | VLLM、量化、批处理、动态路由 | GPU 利用率 ~90% |
