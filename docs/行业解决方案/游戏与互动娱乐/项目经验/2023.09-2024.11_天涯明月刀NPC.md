# 《天涯明月刀》「绝智阿暖」多模态 NPC

| 字段 | 内容 |
|------|------|
| **角色** | 技术负责人 |
| **周期** | 2023.09 – 2024.11 |
| **产业** | [游戏与互动娱乐](../行业解决方案.md) |

## 一句话

将攻略 NPC「阿暖」升级为**多模态智能 NPC**（开放对话 + 语音 + 3D 表现）；对话准确率 **94%**，人设符合率 **99%**，端到端时延 **10s+→1.5s**。

---

## 情境（Situation）

- 原 NPC 以纯文本攻略为主，无法支撑开放世界式对话。
- LLM 幻觉、长上下文、多模态时延是三大工程难题。
- 需在高并发下满足 MMO 玩家体验。

## 任务（Task）

- 主导对话、多模态与性能三条技术线。
- 探索 LLM 在 NPC 场景的**可复用工程模板**。

## 行动（Action）

- **对话：** 混元精调 + RAG（m3e 向量、多轮检索）抑制幻觉。
- **多模态：** 大模型 TTS + 算子加速；语音→3D 面部驱动跨模态方案。
- **性能：** 并行+流式；int8、prefix cache、flash decoding、动态批处理。

## 结果（Result）

| 指标 | 结果 |
|------|------|
| 质量 | 准确率 94%，人设 99% |
| 体验 | 留存 +25%，满意度 92% |
| 性能 | E2E 10s+ → 1.5s |
| 影响 | ICCV 2023 相关成果；开源语音项目 800+ stars |
